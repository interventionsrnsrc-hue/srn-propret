# SRN — srn-proprete.com

Nouveau site officiel SRN, indépendant de tout ancien prestataire ou logiciel.

## Positionnement
**SRN — La propreté. Pilotée.**

Site B2B premium pensé autour de quatre idées : exécution terrain, contrôle, preuve et pilotage multi-sites.

## Expérience V1
- homepage immersive plein écran
- sensation de slides au scroll
- vitre qui se nettoie avec le scroll
- interface visuelle “SRN Control”
- prestations en défilement horizontal
- scène de vitrerie robotisée
- bloc preuves terrain
- formulaire de demande de visite en plusieurs étapes
- responsive mobile
- support `prefers-reduced-motion`
